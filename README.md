# Chanda

Shared expense tracker for two. Monthly net balance, splits, fixed costs, trips and EMIs, built from bank alert emails.

Same stack as Munshi: Vite + React + TypeScript + Tailwind + shadcn/Radix + Supabase.

- Setup: [docs/SETUP.md](docs/SETUP.md)
- Run locally: `npm run dev`
